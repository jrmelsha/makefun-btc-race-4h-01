# cbBTC core-plus-dip bot

make.fun btc-race-4h-01 entry. Only the 4-hour race PnL ranks, and the dev window is a pass/fail gate, so the bot buys variance like an underdog in a rank-order tournament: it holds 70% of its cash in cbBTC from the first bar to the end of the window, and buys one-minute closes 25 bps under their 4-bar SMA with the rest, exiting that sleeve on +80 bps, -150 bps or 240 bars. The dip sleeve's dev profit is what lets the core be this large. Node 22, `main.ts`, standard library plus the vendored kit SDK.
